语言特性

🌏

100%中文关键字

函数、变量、若、否则、对于、循环、结构、枚举……英文关键字在编译阶段直接拒绝。

⚡

原生编译 高性能

编译为C代码再通过系统C编译器生成原生机器码。性能媲美C语言。

🔒

静态类型系统

整数、浮点、布尔、文本、字符。支持结构体、枚举、特质(接口)。

📱

Android APK

完整构建链：javac + d8 + jarsigner，直接生成可安装的APK。

🧮

40+内建函数

字符串、文件I/O、数学、字符处理、内存管理、数组操作。

🖥️

GUI图形界面

X11绑定：窗口、文字绘制、按钮、事件循环。

🚀

自举能力

用曜语写的词法分析器可以解析自身源文件。

🏗️

模块化编译器

单文件3700行C实现。词法→语法→语义→C代码→原生可执行文件。
