曜语 YaoLang 教程 09: 编译器内部原理
架构: .耀 -> 词法 -> 语法 -> 语义 -> C代码 -> gcc -> 可执行文件
编译器: yaolang.c 约3700行C代码
词法: UTF-8源码 -> Token序列 (关键字/标识符/字面量/运算符)
语法: Token -> AST (抽象语法树)
语义: 类型检查 + 作用域管理
代码生成: AST -> C代码 (中文标识符 -> Unicode C标识符)
